# SalesPerformanceDashboard
This project presents an interactive Sales Performance Dashboard built using Power BI. It offers key insights into sales data, allowing stakeholders to monitor performance, track KPIs, and make data-driven decisions.

📊 Features

- Total Sales & Revenue
- Sales by Region & Product
- Trend Analysis over Time
- Top Performing Products and Customers
- Dynamic Filters for deep dive

🛠️ Tools Used

- Power BI Desktop
- DAX for calculated measures
-Data Cleaning & Transformation using Power Query

📁 File

- `data/sales_data.csv` – Source dataset used in the dashboard

- `Salesperformance Dashboard.pbix` – Power BI dashboard
